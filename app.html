How to get the token (2 minutes, once)
  1. Sign in to github.com as Barrix2011.
  2. Open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name: Field portal · Expiration: 1 year · Repository access: Only select repositories → field-portal.
  4. Permissions → Repository permissions → Contents: Read and write and Pages: Read and write. Generate, copy, paste above.

How districts are coloured

Checked in this order — the first rule that fits wins. Uses financial-year-to-date net sales and the latest outstanding, so a district's colour does not jump around when you change the sales period. Productivity is compared with the median district of the same state.
